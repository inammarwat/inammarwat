## Selected Research Projects

### Adaptive Agentic RAG for University Information Assistance
**MEng Dissertation | Al-Farabi Kazakh National University**

Designed and evaluated an adaptive Agentic RAG framework for reliable and traceable question answering over heterogeneous university information sources.

Key components include:

- Query decomposition
- Multi-query retrieval
- Reciprocal-rank fusion
- Source validation and rejection
- Evidence sufficiency scoring
- Reflection / critique
- Adaptive routing
- Grounded answer generation with citations

Evaluation covered **50 general questions and 30 controlled complex questions**, examining faithfulness, completeness, hallucination, citation quality, and latency.

[View Repository](https://github.com/inammarwat/kaznu-agentic-rag-assistant)
